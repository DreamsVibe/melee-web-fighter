Melee Web Fighter

Click the toolbar icon or press Alt+M on any page to drop your fighter onto it.

Character

Falco has his own weight, jumps, falling speed and moves, and his lasers make Sandbag flinch. A page that already has a fighter on it switches at once.

Controller

Chrome can't read the GameCube adapter by itself: the adapter reports itself as a HID device, and Chrome never lets a page or extension claim one. A small helper reads it instead, through the same WinUSB driver Slippi and Dolphin set up with Zadig. To install the helper once, run this in PowerShell from the extension's source folder:


  
Only one program can hold the adapter at a time, so close Dolphin, Slippi or melee-unlocked first
  (and Steam, if its GameCube adapter support is on). If the selected port has no controller, the first one plugged in is used.

  
Standard gamepad mapping

  
Press "remap", then press the pad button you want for each GameCube button.

  

  
Keyboard

  
Press "add key", then the key you want. A key can only do one thing, so taking one that's already
  bound moves it here. Click a key to unbind it. F9 stays the debug draw toggle.

The height sets the engine's scale: px_per_unit = height ÷ Fox's standing height in
  Melee units (measured from his model; the debug overlay shows the result). Speeds and jump heights scale with it.

Sandbag

  

    
    
  

  
Hit it like in Melee: damage adds up and knocks it further. Fox's lasers add damage without making
  it flinch; Falco's make it flinch. With damage off it stays at 0% and every hit knocks it back as at 0%. When it
  leaves the screen it comes back at 0%.
