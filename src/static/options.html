Melee Web Fighter

Click the toolbar icon or press Alt+M on any page to drop Fox onto it.

Controller

The official adapter (and Mayflash in Wii U mode) needs the WinUSB driver on Windows — the same Zadig setup Slippi uses. Close Dolphin/Slippi first: only one program can hold the adapter.

Standard gamepad mapping

Press "remap", then press the pad button you want for each GameCube button.

Keyboard

Arrows or WASD: stick · Shift: walk (half tilt) · Space / I: X (jump) · J: A · K: B · L: R (air dodge, L-cancel) · U: Z · O: D-pad down · F9: debug draw

Display and sound

The height sets the engine's scale: px_per_unit = height ÷ Fox's standing height in Melee units (measured from his model; the debug overlay shows the result). Speeds and jump heights scale with it.

Plugins

Your changes (overrides)

Overrides sit on top of the imported data, reload live while Fox is on a page, and survive re-imports. A JSON override holds only the keys you changed.
